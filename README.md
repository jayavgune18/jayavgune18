## Featured Projects

### 🤖 AI Reconciliation System
> *Automates manual financial transaction matching across multi-format data sources*

**[Live Demo](https://ai-based-reconciliation-system-frontend.onrender.com)** &nbsp;·&nbsp; **[Source Code](https://github.com/jayavgune18/Ai-Based-reconciliation-system)**

Financial teams spend hours reconciling transactions across CSV, XLSX, and PDF files. This platform ingests multi-format uploads, runs **fuzzy matching via Fuse.js**, streams real-time progress through **WebSocket (Socket.IO)**, flags anomalies, and exports audit-ready PDF/XLSX reports — all secured with JWT authentication.

| | |
|---|---|
| **Stack** | React · Node.js · Express.js · MongoDB · Socket.IO · Fuse.js · Multer · PDFKit · XLSX · CSV-Parser · JWT · bcrypt |
| **Architecture** | Multi-format ingestion → fuzzy match engine → WebSocket live progress → anomaly flagging → PDF/XLSX report export → JWT-secured API |
| **Key features** | Automated transaction matching · anomaly detection · real-time WebSocket updates · multi-format upload (CSV/XLSX/PDF) · audit report generation · JWT authentication |

### 💰 AI Expense Scanner
> *OCR-powered receipt processing that eliminates manual expense data entry*

**[Live Demo](#)** &nbsp;·&nbsp; **[Source Code](https://github.com/jayavgune18/AI-Expense-Receipt-Scanner)**

Scans uploaded receipt images with **OCR/AI** to auto-extract merchant, amount, date, and category. Stores results in MongoDB, detects duplicates, sends email notifications, and visualises spend patterns in an interactive analytics dashboard — the entire stack containerised with **Docker Compose + nginx reverse proxy**.

| | |
|---|---|
| **Stack** | React · Vite · Node.js · Express.js · MongoDB · Mongoose · Cloudinary · Docker · Docker Compose · Nginx · Chart.js · Tailwind CSS · JWT · bcryptjs |
| **Architecture** | React SPA → Express REST API → Cloudinary upload → OCR extraction → MongoDB store → analytics layer · All services containerised via Docker Compose with nginx reverse proxy |
| **Key features** | OCR receipt extraction · JWT authentication · duplicate detection · email notifications · interactive analytics dashboard · data backup & restore · Docker Compose single-command deployment |
